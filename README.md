# 控烟计划

一个单机离线 Flutter 应用，用来帮助自己控制每日吸烟上限、拉长吸烟间隔，并逐步减少吸烟。

## 目标

- 不联网，不上传任何个人数据。
- 使用本地 SQLite 数据库记录吸烟与“继续控制”行为。
- 默认每天最多 7 根，可在设置中调整。
- 默认两次吸烟至少间隔 90 分钟，可在设置中调整。
- 上午 11 点后才允许第 1 根；12:00-18:00 和 18:00-23:00 按均匀时间槽分布。
- 到可选吸烟时间时，提示用户可以“抽一支”或“继续控制”，默认鼓励继续忍住。
- 用户打开 App 后可以看到上次吸烟时间、下次可吸烟时间和剩余等待时长。
- 支持到了时间后延后吸烟，真正开始吸之前先打卡，并记录延后时长。
- 支持不到时间憋不住时补录打卡，保证记录真实。
- 统计每日实际吸烟次数、忍住次数、节省估算和连续控制天数。
- 用本地 Canvas 图表展示最近 14 天吸烟趋势。

## 当前规则

基础规则可以在 App 设置中调整：

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 每天吸烟上限 | 7 根 | 超过后首页会提示今日额度已用完 |
| 每次最低间隔 | 90 分钟 | 两次吸烟至少间隔这么久 |

同时保留原始分时段参考节奏：

| 时段 | 时间 | 上限 | 推荐时间槽 |
| --- | --- | --- | --- |
| 上午 | 11:00-12:00 | 1 根 | 11:00 |
| 下午 | 12:00-18:00 | 3 根 | 12:00、15:00、17:30 |
| 晚上 | 18:00-23:00 | 3 根 | 18:00、20:30、22:30 |

23:00 到次日 11:00 是禁烟时段。

## 技术

- Flutter 3.27+
- Android / iOS / macOS / Windows
- 本地 SQLite：`sqlite3` + `sqlite3_flutter_libs`
- 本地应用目录存储：`path_provider`
- 无服务端、无网络依赖、无账号系统
